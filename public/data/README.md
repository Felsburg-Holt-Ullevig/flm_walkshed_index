# Place-name labels

`place-labels.geojson` holds one label point per place, used by
`src/adapters/basemaps/places.ts` for the walkshed label preset. It is generated by
`node scripts/build-place-labels.mjs` (about 106 KB; 573 points). Set `OVERPASS_URL` to use
another OpenStreetMap Overpass API instance if the default is busy.

## Fields

- `name`: place name without its legal suffix (e.g. "Aurora", not "Aurora city").
- `kind`: `municipality`, `community` (census-designated place) or `neighborhood`.
- `tier`: for places, 1 for 2020 population of 100,000 or more, 2 for 25,000 or more, 3
  otherwise. For neighbourhoods, 2 for OSM `place=suburb` (district scale, 42 names) and 3 for
  smaller `neighbourhood`/`quarter` areas (49 names, shown from zoom 14).
- `population`: 2020 census count (not for neighbourhoods).
- `source`: `census:<GEOID>` or `osm:<node|way|relation>/<id>`.

## Status

Provisional. Census and USGS data are public domain; the OpenStreetMap names need only
attribution and keep this file under the ODbL. OpenStreetMap covers about 45 of Denver's 78
official statistical neighbourhoods by name; Washington Park, Congress Park, Cherry Creek,
Country Club, Belcaro, Speer, Hale, Montclair, Virginia Village and others have no OSM point and
are not labelled. Some smaller OSM names are subdivision names. Montbello and Green Valley Ranch
are tagged at the smaller level and appear only from zoom 14. Neighbourhoods cover Denver only;
the same query could cover other cities. Population is the 2020 census and does not change until
the file is rebuilt.
