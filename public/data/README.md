# Place-name labels

`place-labels.geojson` holds one label point per place, used by
`src/adapters/basemaps/places.ts` for the walkshed label preset. It is generated by
`node scripts/build-place-labels.mjs` (about 93 KB; 560 points).

## Fields

- `name`: place name without its legal suffix (e.g. "Aurora", not "Aurora city").
- `kind`: `municipality`, `community` (census-designated place) or `neighborhood`.
- `tier`: 1 for 2020 population of 100,000 or more, 2 for 25,000 or more, 3 otherwise
  (neighbourhoods are always 3).
- `population`: 2020 census count (not for neighbourhoods).
- `source`: `census:<GEOID>` or `denver:<NBHD_ID>`.

## Status

Provisional. Before use beyond the prototype, the data owner should approve both sources,
in particular Denver's indemnification terms. Neighbourhoods cover Denver only; other cities
publish their own neighbourhood data and would each need a source entry here. Population is the
2020 census and does not change until the file is rebuilt from a newer vintage.
