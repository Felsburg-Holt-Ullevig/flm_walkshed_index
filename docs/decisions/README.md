# Decision records

Short records of material accepted decisions: what was decided, the alternatives considered, the consequences, and the condition that would reopen the decision. Add a record when a decision changes architecture, process, or policy. Do not edit an accepted record to change its meaning; add a new record and mark the old one `Superseded by NNNN`. Task status belongs in issues and pull requests, not here.

## Template

```markdown
# NNNN. Title

Status: Accepted | Superseded by NNNN
Date: YYYY-MM-DD

## Context
What required a decision, in two to four sentences.

## Decision
What was decided.

## Alternatives considered
Each alternative and why it was not chosen, one line each.

## Consequences
What this enables, what it costs, and what follows from it.

## Revisit when
The concrete condition that would reopen the decision.
```
